# Madhav E-Commerce Sales Dashboard

## Project Overview
An interactive E-Commerce Sales Dashboard developed using Microsoft Power BI to analyze sales performance, profitability, customer behavior, and product categories.

## Dashboard Features

- **KPI Cards:** Total Orders, Total Quantity, Total Profit, Total Sales.
- **Monthly Profit Trend:** Analyzes month-wise profit and loss.
- **Profit by City:** Compares profit across different cities.
- **Quantity by Category:** Shows category-wise quantity distribution.
- **Top 5 Customers:** Identifies customers based on quantity.
- **Payment Method Analysis:** Analyzes quantity by payment method.
- **Profit by Sub-Category:** Compares profitability across product sub-categories.
- **Interactive Filters:** Quarter and State slicers.
